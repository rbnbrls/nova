## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-41-06 | Tampering | POST /admin/model/switch — model name injection through custom model field | high | mitigate | Validate with `_MODEL_NAME_RE` regex `^[a-zA-Z0-9:_\-./]+$` before any Ollama API call. Reject invalid input with 400. |
| T-41-07 | Tampering | POST /admin/model/pull — model name injection | high | mitigate | Same regex validation as T-41-06. Also enforce one concurrent pull with 409 response. |
| T-41-08 | Tampering | POST /admin/model/delete — attempt to delete active model | high | mitigate | Backend enforcement: compare against `get_active_model_sync()`, return 400 if match (D-14). Frontend disable is additional, not the sole protection. |
| T-41-09 | Tampering | POST /admin/model/delete — model name injection | high | mitigate | Same regex validation as T-41-06. |
