<objective>
Instrument the agent loop with per-iteration timing breakdown, live progress events, and post-turn enrichment dispatch.

**Purpose:** Make the "Nova is thinking..." delay diagnosable by capturing timing at every decision point inside the agent loop. - `test_agent.py` — tests for per-iteration timing and progress pushes
