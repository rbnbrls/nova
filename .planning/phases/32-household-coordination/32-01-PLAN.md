  <name>Task 2: Create grocery list tools (add_grocery_item, list_groceries, mark_purchased)</name>
  <files>services/nova-core/app/tools/groceries.py</files>
  <action>
    Create `app/tools/groceries.py` following the exact patterns from `tasks.py`: `@tool` decorator from `.base`, `get_pool` from `..db`, async functions returning formatted strings.

    **Tool 1 — `add_grocery_item`** (per D-03 and HC-03):
    - Parameters: `title` (required string), `quantity` (optional string)
    - Per D-03: distinct from tasks — this operates on `grocery_items` table, not `tasks`.
    - Auto-dedup logic: Before INSERT, do a SELECT on `grocery_items` WHERE `title ILIKE $1 AND purchased = false`. If a match is found, return `"'{title}' is already on the grocery list."` and do NOT insert. This prevents accidental duplicates from voice or text entry. Use `ILIKE` for case-insensitive matching.
    - If no duplicate: INSERT with `added_by` resolved via `_get_user_uuid(conn, user)`, quantity stored as-is.
    - Return: `"Added '{title}' to the grocery list."` with optional quantity suffix.
    - Import `_get_user_uuid` from `.tasks` — do not duplicate it.

    **Tool 2 — `list_groceries`** (per D-03 and HC-03):
    - No required parameters.
    - SELECT * FROM `grocery_items` WHERE `purchased = false` ORDER BY `added_at` ASC.
    - Join with `users` to get `added_by` name.
    - If empty: return `"The grocery list is empty."`
    - Format: numbered list with title, quantity (if present), and who added it. Example:
      ```
      Grocery list:
      1. Milk (2 liters) — added by Ruben
      2. Bread — added by Meral
      ```

    **Tool 3 — `mark_purchased`** (per D-03 and HC-03):
    - Parameters: `title` (required string)
    - First try exact match: `UPDATE grocery_items SET purchased = true, purchased_at = now(), purchased_by = (SELECT id FROM users WHERE name = $2) WHERE title = $1 AND purchased = false`
    - If `UPDATE 0`, fall back to ILIKE substring match (same pattern as `complete_task` in tasks.py).
    - If found: return `"Marked '{title}' as purchased."`
    - If not found: return `"Could not find '{title}' on the grocery list."`

    Do NOT create a `complete_task`-style delete — items persist for history. Do NOT add a delete-tool (out of scope per D-03).
  </action>
