  <files>services/nova-core/app/tools/chores.py</files>
  <action>
    Create `app/tools/chores.py` following the exact patterns from `tasks.py`. Import `_get_user_uuid` from `.tasks` — do not duplicate.

    **Tool 1 — `add_chore`** (per D-02 and HC-02):
    - Parameters: `title` (required), `assignee` (optional string, enum ["Ruben", "Meral", "household"], defaults to caller), `recurrence_pattern` (required string), `rotation_group` (optional string), `due_at` (optional ISO 8601 string)
    - Validate `recurrence_pattern` is non-empty — if blank or whitespace-only, return `"Error: recurrence_pattern is required for chores."`
    - INSERT into `tasks` with `is_chore=true`, `recurrence_pattern`, `rotation_group`, `last_rotation_assignee_id=NULL` initially, and standard task fields (title, assignee, due_at). Use the same INSERT pattern as `add_task` in tasks.py.
    - Return: `"Added chore '{title}' for {assignee} (recurring: {recurrence_pattern})."` Append rotation group if provided.

    **Tool 2 — `list_chores`** (per D-02 and HC-02):
    - Parameters: none required; optional `rotation_group` (string) to filter.
    - SELECT from `tasks` WHERE `status = 'active' AND is_chore = true`, filtered by rotation_group if provided. JOIN with users for assignee name and last_rotation_assignee name. ORDER BY created_at ASC.
    - For each chore, format with: title, assignee, recurrence pattern, rotation group (if set), and a fairness indicator.
    - Compute fair share: for each chore in the results, query `chore_rotation_log` for completions in the same rotation_group in the last 30 days. Count completions per user. If any user has more than 1 completion more than the other, append a nudge line: `"⚖️ Fair-share: Ruben has done this 3x, Meral has done it 1x this month."` (Use the actual counts and names.)
    - If no chores: return `"No recurring chores configured."`
    - Format example:
      ```
      Recurring chores:
      1. Dishes — assigned to Meral [weekly] [kitchen]
         ⚖️ Fair-share: Ruben has done this 3x, Meral has done it 1x this month.
      2. Vacuum living room — assigned to Ruben [biweekly]
      ```

    **Tool 3 — `complete_chore`** (per D-02 and HC-02):
    - Parameters: `title` (required string)
    - Find matching active chore: same exact-match + ILIKE fallback as `complete_task` in tasks.py, but with `AND is_chore = true AND status = 'active'`.
    - If not found: return `"Could not find active chore matching '{title}'."`
    - If found and `recurrence_pattern IS NOT NULL`:
      a. Mark the current task as completed: `UPDATE tasks SET status = 'done', completed_at = now() WHERE id = $1`
      b. Log rotation: INSERT into `chore_rotation_log` (chore_id, completed_by, rotation_group)
      c. Compute next assignee: if `rotation_group IS NOT NULL` and household has both Ruben and Meral (query users table for count >= 2 in household), determine next assignee. If `last_rotation_assignee_id` is Meral, next is Ruben, and vice versa. If no last_rotation (first completion), flip the original assignee.
      d. INSERT a new task (the next chore instance) with: same title, assignee = next_assignee, same recurrence_pattern, same rotation_group, no due_at (or same due_at shifted — keep it null for simplicity), `is_chore=true`, `last_rotation_assignee_id = completed_by` (the person who just did it).
      e. Compute fairness: same query as list_chores (last 30 days in rotation_group). If any user is ahead by 2+, append a fairness note.
      f. Return: `"Completed chore '{title}'. Next instance assigned to {next_assignee}.{fairness_nudge}"`
    - If found but NOT recurring (`recurrence_pattern IS NULL`):
      a. Just mark done (regular completion).
      b. Return: `"Completed chore '{title}'."`

    Use the same `_fetchrow_side_effect`-style helpers as `_get_user_uuid` for user lookups. Compute fairness only when `rotation_group` is set.

    Do NOT add a `delete_chore` tool — out of scope. Do NOT auto-schedule due dates from recurrence patterns — the chore simply re-queues with a new assignee on completion.
  </action>
