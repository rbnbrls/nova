       b. Resolve the effective room: `resolved_room = room or req.room or "default"`.
       c. Import `voice_room_manager` from `.voice_rooms`. Import `re` at the top of the file.
       d. Add a compiled regex at module level (outside the handler) for whoami detection:

       ```python
       _WHOAMI_PATTERN = re.compile(
           r"^(?:nova,?\s+)?(?:i'?m |i am |this is |it'?s )(r(u|e)ben|m[eé]ral)$"
           r"|^(?:nova,?\s+)?(r(u|e)ben|m[eé]ral) speaking$",
           re.IGNORECASE
       )
       ```

       e. Before the `try:` block (after resolving user and room), check for whoami intent: (D-03 — "I'm X" at satellite; D-07 — whoami updates room's active user)

       ```python
       # WhoAmI intent detection: check if the message is an identity claim
       if last:
           m = _WHOAMI_PATTERN.match(last.strip())
           if m:
               claimed = (m.group(1) or m.group(3)).lower()
               # Normalize "méral" or "méral" to "Meral" (DB spelling)
               if claimed.startswith("m"):
                   claimed = "Meral"
               elif claimed.startswith("r"):
                   claimed = "Ruben"
               await voice_room_manager.set_active_user(resolved_room, claimed)
               return ChatCompletionResponse(
                   model=req.model or settings.nova_model,
                   choices=[Choice(message=ChatMessage(role="assistant", content=f"Okay {claimed}, I will remember you for this room."))],
               )
       ```

       f. After whoami check, resolve the active user for the room:

       ```python
       resolved_user = user or req.user or "household"
       if resolved_room != "default" and resolved_user == "household":
           resolved_user = await voice_room_manager.get_active_user(resolved_room)
       ```

        This ensures: user from query param takes precedence (for future use), otherwise resolve from room.

        g. Pass `resolved_user` to `run_agent()` instead of the old `resolved_user`. (D-09 — reuse existing identity system)
        The existing agent loop (run_agent) already formats `{user}` into the system prompt per line 28 of agent.py, and tools.call_tool receives `user=user` for attribution.

    **Why the whoami regex is safe:** It only matches exactly the identity patterns for known names. Messages like "I'm running late" will not match because they don't end with "Ruben" or "Meral". The pattern is compiled once at module level for performance.

    **Why room override ordering:** The query param `?user=Ruben` (set by per-user HA Assist pipeline config) takes precedence over room resolution. When both room and user are provided, the explicit user wins. When only room is provided, room-based resolution kicks in.
