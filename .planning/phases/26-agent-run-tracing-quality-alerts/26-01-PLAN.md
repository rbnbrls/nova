## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-26-01 | Tampering | Trace POST to OpenObserve | low | mitigate | Fire-and-forget with 5s timeout; payload is structured dict (no user-controlled freeform text in HTTP body) |
| T-26-02 | Information Disclosure | Trace payload contents | medium | mitigate | Only emit fields approved by D-01 (channel, user name, latency, token count, tool calls names/status, errors); no message content, no PII beyond household name (already in audit_log) |
| T-26-03 | Denial of Service | OpenObserve ingestion | low | mitigate | Fire-and-forget pattern; asyncio.create_task never awaited; all httpx exceptions caught and logged at warning level; agent response path never blocked |

| T-26-SC | Supply Chain | Python package installs | low | accept | No new packages required—httpx, asyncio, dataclasses all existing dependencies |
