    a) `async def _ha_headers() -> dict` — Returns `{"Authorization": f"Bearer {settings.nova_ha_token}", "Content-Type": "application/json"}`. If token is empty, returns empty dict (callers check).

    b) `async def _ha_get(path: str) -> dict | list` — 
       - Builds `url = f"{settings.nova_ha_url.rstrip('/')}/api/{path.lstrip('/')}"`
       - Uses `async with httpx.AsyncClient(timeout=10) as client`
       - GETs with headers from `_ha_headers()`
       - Calls `resp.raise_for_status()` — httpx raises on 4xx/5xx
       - Returns `resp.json()`
       - Catches `httpx.HTTPStatusError` → returns `{"error": f"HA API error {resp.status_code}: {resp.text}"}`
       - Catches `httpx.RequestError` → returns `{"error": f"HA connection failed: {e}"}`
       - If token is empty, returns `{"error": "HA not configured — set NOVA_HA_TOKEN and NOVA_HA_URL"}`

    c) `async def _ha_post(path: str, data: dict | None = None) -> dict | list` —
       Same as _ha_get but POSTs with optional JSON body.
       Posts to `url = f"{settings.nova_ha_url.rstrip('/')}/api/{path.lstrip('/')}"`
       Returns resp.json() after raise_for_status.
       Same error handling as _ha_get.

         ```json
         {

           "properties": {
             "domain": {"type": "string", "description": "Service domain, e.g. light, climate, switch, scene, lock, cover"},

           },
           "required": ["domain", "service"]
         ```

       - Builds POST body: start with `{}`. If `target` is given, add `{"entity_id": target}`. If `data` is given, merge/update with the data dict (so `data` can override or add fields).
       - Calls `await _ha_post(f"services/{domain}/{service}", body)`.

       - `name="ha_query_presence"`
       - Description: "Check if a specific person is home or away, based on Home Assistant person entities and their associated device_trackers. Omit person_name to list all household members' presence."
       - Parameters:
         ```json
         {
           "type": "object",
           "properties": {
             "person_name": {"type": "string", "description": "Person name (case-insensitive substring match), e.g. Ruben, Méral. Omit to list all persons."}
           }
         }
         ```
       - Implementation:
         1. Calls `await _ha_get("states")` to get ALL states.
         2. Filters results to entities whose `entity_id` starts with `"person."`.
         3. If `person_name` is given, filters to entities whose `entity_id` or `attributes.friendly_name` contains the person_name (case-insensitive).
         4. For each matching person entity, extracts: `entity_id`, `state` (typically "home" or "not_home"), `friendly_name`.
         5. Returns formatted string like:
            `"person.ruben: home\nperson.meral: not_home"`
            Or: `"Ruben is home."` / `"Ruben is not home."` for single-person queries.
            Or: `"No person entities found in HA."` if none.
            Or error string if HA unreachable.
