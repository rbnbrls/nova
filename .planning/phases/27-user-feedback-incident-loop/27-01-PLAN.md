  <name>Feedback detection, context capture, and issue filing</name>

  <behavior>
    **Per D-01, D-02, D-03, D-04**

    ### `detect_feedback_text(text: str) -> bool`
    - Returns `True` for: "that was wrong", "that's incorrect", "that is not right",
      "not what I meant" — with optional "Nova, " prefix, case-insensitive substring match.
    - Returns `False` for empty string, non-matching text, whitespace-only.

    ### `detect_feedback_reaction(emoji: str) -> bool`
    - Returns `True` for "👎" (single emoji string).
    - Returns `False` for None, empty, other emoji, non-emoji strings.

    ### `FeedbackContext` class (per-user conversation context cache)
    - `capture(user: str, turn: TurnContext)` — appends turn, trims to max 3.
    - `get(user: str) -> list[TurnContext]` — returns recent turns (empty list for unknown user).

    ### `TurnContext` dataclass
    Fields: `user_message`, `agent_reply`, `tool_calls`, `errors`, `iteration_count`,
    `latency_ms`, `channel`, `timestamp` — matches the data shape from the tracer's AgentTrace.

    ### `redact_context(context: list[TurnContext]) -> list[TurnContext]`
    - Replaces phone numbers (regex `\+\d{7,15}`) with `[PHONE]` in `user_message` and `agent_reply`.
    - Returns a deep copy, does not mutate input.

    ### `build_issue_body(user, channel, context, trigger) -> str`
    - Produces a structured Markdown string with: user, channel, trigger, timestamp,
      redacted conversation turns (user message, agent reply, tool calls, errors truncated).
    - Each turn clearly labeled, all fields truncated to safe limits (500 chars message, 1000 chars tool calls).

    ### `file_feedback_issue(user, channel, context, trigger) -> int | None`
    - Creates a Forgejo Client using `app.forgejo.ForgejoClient` with settings from `app.config.settings`.
    - Issue title: `"User feedback from {user} ({channel})"`.
    - Issue labels: `["feedback"]`.
    - Returns the issue number on success, `None` on any exception (catches all).
    - Logs appropriately at each step.
    - Skips silently if Forgejo is not configured (no `forgejo_url` or no `forgejo_token`).

    ### Module-level singleton
    - `feedback_context = FeedbackContext()` — shared instance imported by Plan 02 callers.
  </behavior>

  <implementation>
    Create `app/feedback.py` with all classes/functions above.
    The module has zero knowledge of channels or agent internals — it only
    sees `TurnContext` instances and produces Forgejo issue payloads.
    All HTTP calls go through the existing `ForgejoClient` (not raw httpx).

    File `tests/test_feedback.py` following project patterns:
    - AsyncMock for ForgejoClient patching
    - `patch.dict(os.environ, ...)` for config-dependent paths
    - Phone number redaction tests with realistic E.164 numbers
    - Edge cases: empty input, non-string input, whitespace, emoji mix
  </implementation>
</feature>
